# PSI LABS AI — Комплекс решений для генератора экзаменационных билетов

Данный репозиторий содержит материалы, исходный код, документацию и автоматические тесты для первой и второй лабораторных работ (консольное и десктопное графическое приложение распределения экзаменационных билетов).

---

## 📚 Реализованные проекты

| Лабораторная работа | Тип приложения | Стек технологий | Статус |
|---|---|---|:---:|
| **[Лабораторная №1](lab1/)** | Консольный генератор билетов с сохранением в Excel | Python 3, openpyxl, pytest | ✅ **Готово** |
| **[Лабораторная №2](lab2/)** | Десктопное UI-приложение распределения билетов | Python 3, Tkinter/ttk, openpyxl, python-docx, pytest | ✅ **Готово** |

---

## 🛠️ Общие требования к окружению

- **Python**: 3.10+ (рекомендуется 3.11–3.14)
- **Git**: 2.x+
- **VS Code** или Antigravity IDE

---

## 🚀 Быстрый старт

### Лабораторная №1 (Консольное интерактивное приложение)
```bash
cd lab1
pip install -r requirements.txt
python run.py
pytest
```
Подробная документация в [lab1/README.md](lab1/README.md).

### Лабораторная №2 (Десктопное GUI-приложение)
```bash
cd lab2
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
pytest
```
Подробная документация в [lab2/README.md](lab2/README.md).
