# PSI LABS AI — Комплекс лабораторных работ по разработке с ИИ-помощниками

Данный репозиторий содержит материалы, исходный код и тесты для серии лабораторных работ по курсу разработки с использованием современных AI-ассистентов (GitHub Copilot, LLM, агентные среды).

---

## 📚 Структура курса

| Лабораторная | Тема / Проект | Стек | Статус |
|---|---|---|:---:|
| **[Лабораторная №1](lab1/)** | Консольный генератор экзаменационных билетов с записью в Excel | Python 3, openpyxl, pytest | ✅ **Готово** |
| **[Лабораторная №2](lab2/)** | Десктопное UI-приложение распределения билетов (Tkinter, Word docx, Excel) | Python 3, Tkinter, openpyxl, python-docx, pytest | ✅ **Готово** |
| **Лабораторная №3** | Конвертер валют на базе SpecKit и Antigravity | В разработке | ⏳ Запланировано |
| **Лабораторная №4** | Финальный проект: Мобильное приложение | В разработке | ⏳ Запланировано |

---

## 🛠️ Общие требования к окружению

- **Python**: 3.10+ (рекомендуется 3.11–3.14)
- **Git**: 2.x+
- **VS Code** или совместимая IDE с плагинами GitHub Copilot / Antigravity

---

## 🚀 Быстрый старт

### Лабораторная №1 (Консольное приложение)
```bash
cd lab1
pip install -r requirements.txt
python run.py
pytest
```
Подробности в [lab1/README.md](lab1/README.md).

### Лабораторная №2 (Приложение с графическим интерфейсом)
```bash
cd lab2
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python run.py
pytest
```
Подробности в [lab2/README.md](lab2/README.md).
