# Лабораторная работа №1: Генератор экзаменационных билетов

Консольное приложение на языке Python для автоматизированного распределения экзаменационных билетов среди студентов с сохранением истории в файл Microsoft Excel (`journal.xlsx`).

---

## 📋 Требования технического задания и реализация

| Требование ТЗ | Описание реализации | Статус |
|---|---|:---:|
| **Тип приложения** | Консольное интерактивное CLI-приложение | ✅ Выполнено |
| **Язык разработки** | Python 3 (совместимо с 3.10+) | ✅ Выполнено |
| **Хранилище данных** | Файл `journal.xlsx` (библиотека `openpyxl`) | ✅ Выполнено |
| **Подсказка при старте** | При запуске выводится `Для выхода нажмите ESC.` | ✅ Выполнено |
| **Запрос данных** | `Last name: ` и `First name: ` с подтверждением Enter | ✅ Выполнено |
| **Генерация билета** | Случайное число в диапазоне от 1 до 20 включительно | ✅ Выполнено |
| **Вывод номера билета** | В консоль выводится `Билет № <число>.` | ✅ Выполнено |
| **Мгновенное сохранение** | Запись сохраняется на диск сразу после ввода каждого студента | ✅ Выполнено |

| **Обработка клавиши ESC** | Нажатие ESC в момент ожидания ввода корректно завершает работу | ✅ Выполнено |
| **Защита от блокировки файла** | При открытом в Excel файле приложение выводит понятное сообщение и предлагает закрыть файл для повтора | ✅ Выполнено |

## 🏗️ Архитектура проекта

Код спроектирован по принципам чистой архитектуры (Clean Architecture / SOLID):

```text
lab1/
├── requirements.txt                 # Зависимости проекта (openpyxl, pytest)
├── pyproject.toml                   # Конфигурация проекта и pytest
├── run.py                           # Точка быстрого запуска приложения
├── README.md                        # Документация лабораторной работы
├── src/
│   └── ticket_generator/
│       ├── __init__.py              # Экспорт публичных классов
│       ├── models.py                # Модель данных StudentRecord (валидация, нормализация)
│       ├── generator.py             # Интерфейс TicketGenerator и RandomTicketGenerator
│       ├── storage.py               # ExcelJournalStorage (создание, аппенд, обработка lock-файлов)
│       ├── console.py               # WindowsConsoleIO (msvcrt) и StreamConsoleIO с поддержкой ESC
│       ├── app.py                   # TicketApp — координатор логики приложения
│       └── __main__.py              # CLI запуск модуля: python -m ticket_generator
└── tests/
    ├── conftest.py                  # Pytest фикстуры (временный Excel, мок-консоль)
    ├── test_models.py               # Тесты валидации моделей
    ├── test_generator.py            # Тесты диапазона и генерации билетов
    ├── test_storage.py              # Тесты создания Excel, добавления записей и блокировок
    ├── test_console.py              # Тесты ввода, обрезки пробелов, пустых строк и ESC
    └── test_app.py                  # Интеграционные сценарии полного цикла (все сценарии ТЗ)
```

### Структура таблицы Excel (`journal.xlsx`)

## ⚙️ Установка и запуск

### 1. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 2. Запуск приложения

```bash
python run.py
```

*Дополнительные опции запуска:*
```bash
# Указать альтернативное имя или путь к файлу журнала:
python run.py --file my_journal.xlsx

# Задать кастомный диапазон номеров билетов:
python run.py --min-ticket 1 --max-ticket 30
```

## 🔍 Чек-лист проверки результата (согласно ТЗ)

1. **Сценарий 1:** Запустить, ввести трёх студентов, выйти по ESC — в файле создаются 3 строки данных и шапка.
2. **Сценарий 2:** Запустить снова, ввести двух студентов — в файле становится 5 строк данных, первые 3 остаются неизменными.
3. **Сценарий 3:** Завершение через диспетчер задач после добавления студента — запись гарантированно сохранена на диске.
4. **Сценарий 4:** Открыть `journal.xlsx` в Excel и попытаться ввести студента — приложение выводит понятное предупреждение, предлагает закрыть файл в Excel и нажать Enter для продолжения (не падает с ошибкой).
5. **Сценарий 5:** Нажать Enter на пустом поле ввода — приложение повторяет запрос.
